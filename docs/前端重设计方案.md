## 1. 背景与现状诊断

OWCopilot 是本地优先的开放世界叙事 AI 工作台（Vue 3 + Vite + TS 前端，FastAPI 后端，21 组 REST 路由 + SSE 长任务）。后端能力扎实：34 条确定性校勘规则、影响分析、接地生成、审阅闭环、导出交付。

前端现状问题：

- **信息架构平铺**：26 个一级页面、6 组导航，是"功能清单"而非"工作流"，新用户认知负担重。
- **视觉同质化**：深空蓝黑 + 烫金是市面 AI 工具大众脸（甲方明确指出"太土"）。
- **组件层缺失**：各页控件自造，样式与交互不一致，改一处动全身，是历史 bug 温床。

重做目标：**重构信息架构 + 统一组件层 + 浅色视觉系统**，且全程零新增 bug（保障体系见 §10）。

## 3. 视觉系统规范「云上智库」

设计立意：**白昼观星**。暖白纸面为底、哑光古金为饰、风青为功能色。星空母题以金线星座白描（细金线 + 云海 + 柔光晕）呈现，书卷气贴合"智库"。

**金色的纪律**：哑光描金，不大面积发光；金色只给"饰"——描边、角饰、分隔线、激活态、图标。浅色下"贵气"靠描边与阴影精细度，P1 验收重点。

### 3.2 深度模型与几何

- **分层靠投影 + 细金描边**（浅色不能用辉光）：底层 paper-2 → 卡片 card + `--ow2-shadow` + 1px `--ow2-gold-soft`。
- **圆角 10px**（面板）/ 8px（控件）/ 7px（小徽标），替代旧切角；卡片可加 1px 内框角饰线。
- **菱形钻母题保留**：导航激活标记、标签页标记、列表项目符号统一 6px 旋转 45° 菱形。
- **背景**：`linear-gradient(175deg,#EEF3F4,#F6F1E7 34%,#F3ECDC)` + 金线云纹 / 星座白描 SVG，缓慢漂移（可降级关闭）。

### 3.3 字体（贴近原神，免费可商用替代栈）

> 说明：原神实际 UI 字体为汉仪定制商业字体（汉仪文黑系），**不可直接嵌入 Web**。以下用免费可商用字体逼近其"衬线描金标题 + 饱满圆润正文"的气质。

| 角色 | 栈 | 说明 |
|---|---|---|
| 展示标题 `--ow2-serif` | `"Noto Serif SC","Songti SC","SimSun",serif` | 600–900 字重；页面大标题 / 世界名 / 卡片题，衬线描金感 |
| 正文 / UI `--ow2-sans` | `"HarmonyOS Sans SC","PingFang SC","Noto Sans SC","Microsoft YaHei",system-ui,sans-serif` | 圆润黑体栈；UI 控件优先 **500 字重**（比 400 更接近原神饱满感） |
| 拉丁描金小标 `--ow2-overline` | `"Cinzel",Georgia,serif` | 沿用；`letter-spacing:.28em` 小写大标 |
| 展示数字 `--ow2-num` | `"Marcellus","Noto Serif SC",serif` | 仪表 / 大指标的衬线数字；密集表格回退 sans + `tabular-nums` |
| 可选点缀 | 得意黑 Smiley Sans（OFL） | 仅教程卡 / 空态标题少量点缀，可不上 |

字体加载：Google Fonts 引入 Noto Serif SC / Noto Sans SC / Cinzel / Marcellus；正式交付前转为自托管 woff2 子集（本地优先产品，不能依赖外网）。

### 3.4 图标

线性 SVG 图标，1.5px 描边，默认墨色、激活描金；统一 24 视图框。不用 emoji 充当图标。

## 5. 主页设计详案（总览）

### 5.1 布局（自上而下）

1. **题头区**：世界名（Noto Serif SC 大字）+ Cinzel overline `ASTRAL ARCHIVE` + 世界徽记（由世界 ID 生成的星座纹章，复用 `StarEmblem` 思路，浅色金线版）。
2. **星轨仪**（视觉中心，见 5.2）+ 8 颗指标卫星卡（阵营 / 人物 / 地点 / 任务 / 事件 / 对话树 / 术语 / 素材），点击跳对应分库。
3. **三快捷卡**：继续审阅（待审条数朱砂徽标）/ 运行校勘（上次结论 X 错 Y 警）/ 世界问答。
4. **最近变更流**：每条带来源徽记（人工·金 / AI·紫 / 已采纳·青）。
5. **空世界态**：双入口大卡「导入既有素材 / 一句话创世」+ 一行小字"或先播种示例世界体验"。

### 5.2 星轨仪（D5：three.js 优先，SVG 兜底）

- **3D 方案（首选）**：中心就绪度环仪 + 卫星沿倾斜轨道缓慢公转，自发光关闭、改用描金边 + 暖投影材质以贴合浅色；悬浮卫星出 tooltip，点击跳转。
- **降级触发条件**（任一命中即切 SVG）：首屏 LCP > 2.5s；`prefers-reduced-motion`；WebGL 不可用；低端设备 `hardwareConcurrency <= 4`。
- **SVG 兜底方案**：双环刻度 + 金渐变就绪度弧 + 静态卫星卡（即风格板呈现的样子）。两方案对外 props 完全一致：`{ readiness: number, stats: StatItem[] }`，切换不改页面代码。
- 复用现有 `Graph3D.vue` 的 three.js 依赖（`3d-force-graph` / `three-spritetext` 已在 dependencies），不新增重型依赖。

### 5.3 加载

星轨仪进场：外环刻度逐格点亮、卫星沿轨道滑入（≤600ms，可降级）；数据未就绪显示骨架环。

## 6. 分页设计详案

> 每页统一回答四件事：展示什么 / 如何展示 / 输入控件 / 加载动画。通用控件规范见 §7，此处只写页面级要点。

### 6.1 世界档案（招牌区：分库标签 + 左列表右详情）

- **骨架**：顶部 5 个分库标签（菱形钻标记），其下统一「左列表 + 右详情」。
- **设定档案**：左列表按类型分组；顶部**搜索框**（placeholder "搜索名称 / ID / 描述 / 标签"）+ **类型筛选 OwSelect**（菱形项符，全键盘可达）；右侧详情卡：字段、关系链、来源徽记，角饰面板。
- **人物分库**：角色卡网格（立绘位 + 一句话概念 + 阵营标签），点开右侧滑出完整卡。
- **图谱 / 时间线**：保留现有 SVG 星图与编年轴全部交互逻辑，仅统一控件皮肤（缩放条、全屏钮换成 Ow* 样式）并反色为浅色金线。
- **世界分析**：指标卡网格 + 欠发育势力 / 待补缺口列表。
- **加载**：列表骨架行；图谱"星座逐星点亮"。

### 6.2 创作（左表单 + 右产物）

- **创世工坊**：核心想法 = 长文本域（右下字数环 0/4000，近限变朱砂）；题材 / 基调 / 纪元 / 规模 = **图标选择卡**（一排带图标与一句注解的卡片，点选描金边，替代下拉）；「接地与参考」= OwSwitch。
- **扩写工坊**：焦点 = **实体选择器 OwEntityPicker**（搜索 + 按类型分组 + 最近使用）；扩写角度 = 可留白长文本。
- **任务·对话·台词**：沿用四标签（任务草稿 / 对话树 / 台词 / 物案），左填写右出结果。
- **生成中（SSE 分阶段）**：水平阶段链，每完成一阶段点亮一颗星并显示阶段名（解析 → 检索 → 起草 → 批驳 → 定稿），星间连线逐段镀金；可最小化为右上角后台任务徽标。
- 产物统一落审阅台，页内提示"已送审阅台候批"。

### 6.3 素材入库

- **文稿提炼**：标题 OwInput + **拖放区**（旋转虚线环，拖入悬停时环加速镀金）+ 粘贴文本域；提炼后缺口清单用朱砂编号列表。
- **表格导入**：三步 **OwStepper**（选文件 → 预演 → 写入）；预演结果 = 增 / 改 / 冲突三色统计卡，冲突行逐条勾选；「预演（不写入）」次按钮、「确认写入」主按钮。
- **灵感库**：收录卡片流 + FilePicker；明确标注"仅用于检索，不写入正式设定"。
- **加载**：预演进度条走"亮点逐站停靠"动画。

### 6.4 质检

- **校勘修复**：顶部**署名 OwInput**（行内 ? tooltip："记录操作员姓名，非密码"）+ 主按钮「运行校勘」；结果按严重度三栏（错误·朱砂 / 警告·琥珀 / 提示·青空）；每条违例卡含位置、证据、「应用修复」「回滚」按钮 + 影子验证结论徽标。
- **影响分析**：行式编辑器（改动类型 OwSelect + OwEntityPicker + 参数 OwInput，可增删行）；结果分「必须同步改」「建议复查」两组手风琴。
- **专项清查 / 版号合规**：主题 OwInput + 范围 OwSelect；结果可逐条勾选清单，支持导出工单；合规页闭环状态（标记 → 指派 → 整改 → 复扫 → 签核）用 OwStepper 呈现。
- **加载**：审计运行时**雷达扫掠**动画覆盖统计环。

### 6.5 协作交付

- **审阅台**（流量最大页，重点打磨）：顶部署名 + 批量操作栏；卡片流，每条产物卡含类型徽记、diff 预览、「采纳（金主钮）/ 请修订（紫描边）/ 退回（灰描边）」三钮；决定后卡片定格为已决态（不可再改，与后端一致）。
- **世界问答**：底部**对话式输入栏**（OwTextarea 自适应高度，右侧镀金发送钮，hint "Enter 发送 · Shift+Enter 换行"）；回答卡带引用出处角标，点击跳分库；「构建总览索引」为带说明的次按钮。
- **本地化**：覆盖率统计环 + 字符串状态列表（待译 → 已译 → 待校 → 定稿 OwTabs 过滤）。
- **导出交付**：三张产物卡（设定集 / 世界包 / 引擎包），各带格式 OwSelect + 「导出」主钮，完成后显示校验和徽记。
- **变更史**：快照时间流 + 两两对比（增 / 删 / 改三色 diff），「恢复到此快照」危险钮二次确认。

### 6.6 系统

- **设置**：供应商图标卡单选（DeepSeek / OpenAI / Anthropic / Kimi / Zhipu / Qwen / Doubao / custom）；API Key = 密码框 + 「测试连接」次钮 + 连通状态灯；**显著提示"密钥仅存本地进程内存"**。另含外观区：动效总开关（保留旧"专业模式"）。
- **工作区**：世界卡片网格 + 新建 / 导入世界包；删除 = 朱砂危险钮 + 二次确认 OwModal。

## 7. 组件库规范（14 件，P1 交付）

目录 `frontend/src/components/ow/`，命名 `Ow*.vue`，全部：props/emits 全类型化；只消费 `--ow2-*` tokens；`prefers-reduced-motion` 降级；焦点可见态。

| 组件 | 关键 API | 要点 |
|---|---|---|
| `OwButton` | `variant: primary/secondary/ghost/danger`, `loading`, `disabled` | primary 金渐变底深棕字；loading 内嵌轨道环（小卫星绕核） |
| `OwInput` | `modelValue`, `placeholder`, `maxlength`, `required` | focus 描金 + 3px 浅金光晕；必填标朱砂"必填" |
| `OwTextarea` | `modelValue`, `maxlength`, `autosize` | 右下字数环，≥90% 变朱砂 |
| `OwSelect` | `options`, `modelValue`, `placeholder` | 自研下拉（菱形项符、↑↓ 键导航、Enter 选定、Esc 关闭、点击外部关闭） |
| `OwSwitch` | `modelValue: boolean` | 滑钮，开启态风青底 |
| `OwTabs` | `items`, `modelValue` | 分库标签：菱形标 + 激活下划金线 |
| `OwPane` | `variant: plain/ornament` | 圆角 10 + 细金描边 + 暖投影；ornament 加内框角饰 |
| `OwBadge` | `tone: gold/violet/green/amber/cinnabar/sky` | 来源与状态徽记 |
| `OwTag` | `tone`, `removable` | 实体类型 / 标签 |
| `OwStat` | `label`, `value`, `hint`, `to` | 指标块，可点击跳转，hover 上浮 |
| `OwEmpty` | `title`, `hint`, `cta` | 星座空态插画 + 引导按钮（空态即教程） |
| `OwSkeleton` | `lines`, `shape` | 米白底浅金 shimmer，形状贴合最终布局 |
| `OwStepper` | `steps`, `current` | 阶段链，逐站镀金 |
